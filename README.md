# 小兔🐰的健康追蹤表 — 版本2

手機開啟：https://iamyugachang.github.io/bunny-diet-diary/?v=2

## 每日追蹤
- 體重、體脂；不用每天量。
- 就寢與起床時間，自動跨午夜計算；預設睡眠目標每天8小時。
- 五個水杯，每杯500cc、目標2500cc，可取消或記為0。
- 運動時數手填，小數點一位；有氧/重訓複選，快捷項目與自由輸入。預設每週3次，週一到週日；當天時數大於0算1次，同日多項仍算1次。不要求每次滿1小時。明確填0表示休息，空白表示未記錄。
- 自選綠黃紅狀態與可選感受標籤。
- 保留原版飲食、熱量、六大類份數、餐別、照片與貼上估算。

## 月末回顧
- 首末有效體重/體脂變化與測量日期；體脂差為百分點。
- 體態折線圖，可查看每筆原始數據。
- 睡眠/喝水達成率以有填日期為分母，未填另列。
- 運動按已結束、有紀錄的週計算週目標進度；跨月週依週日歸屬並採全週資料，進行中另列。本月次數及時數只計本月。
- 下月微調計畫、獎勵、完成及領取勾選。

## 儲存與備份
靜態網頁，無帳號、無雲端同步。所有個人紀錄保存在使用者自己的瀏覽器；網頁更新不會上傳紀錄。沿用原版儲存鍵，版本2增加健康欄位，不刪除既有飲食資料。

數字欄位離開時儲存，隱藏/離開頁面也會嘗試儲存合法輸入；文字及按鈕立即保存。不重建正在輸入的欄位。儲存空間不足會顯示警告，不自動刪除照片。

設定可匯出完整JSON備份（含照片、飲食、健康及月計畫），也支援原版備份。換裝置、換瀏覽器、清網站資料前請先匯出；瀏覽器內的升級快照不是外部備份。

照片估算流程維持：照片傳到兔兔聊天室 → 得到六大類份數 → 貼進App。沒有內建自動照片辨識，營養數字是估算，不是醫療診斷。

## 開發驗證
不需安裝第三方套件，Node內建測試：
```sh
node --test tests/*.test.cjs
node --check health-core.js
node --check health-ui.js
```

核心：`health-core.js`；健康/月回顧互動：`health-ui.js`；手機樣式：`health-v2.css`；既有飲食功能：`index.html`。
